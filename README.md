# External-Developers Guide

このリポジトリは、Kubernetesクラスター上で動くアプリケーションのデプロイ環境一式を管理しています。開発者はこれらのマニフェストを通じて、機密情報の取得、ストレージの確保、外部公開をセルフサービスで行えます。

## 📂 構成ファイルの説明

| ファイル名 | 役割 | 説明 |
| :--- | :--- | :--- |
| `pvc.yaml` | **ストレージ予約** | NFSサーバーから専用の保存領域（PersistentVolume）を確保します。 |
| `externalsecret.yaml` | **機密情報の同期** | **OpenBao** に保存されたパスワードやAPIトークンをK8sのSecretとして取り込みます。 |
| `nginx.yaml` | **アプリ本体 (Pod)** | メインのアプリケーション（Python/Nginx等）の実行定義とリソース制限を行います。 |
| `ingress.yaml` | **外部公開設定** | ドメイン（`*.4nm1tsu.com`）経由でブラウザからアクセス可能にします。 |
| `application.yaml` | **ArgoCD管理** | 上記すべてのリソースを GitOps で自動同期するための定義ファイルです。 |

---

## 🛠 外部インフラサービスの利用方法

### 1. 🔐 機密管理 (OpenBao)
認証情報やAPIキーをソースコードに直接書かず、安全に管理するために **OpenBao** を使用します。

* **URL:** `https://openbao.4nm1tsu.com`
* **役割:** 開発者がUI上で登録した値を、`externalsecret.yaml` が自動で Pod の環境変数へ注入します。
* **利用手順:**
    1.  UIにログインし、`external-developers/` パス配下にシークレットを作成。
    2.  `externalsecret.yaml` の `remoteRef.key` に作成した名前を指定。
    3.  アプリ側では環境変数（例: `APP_API_TOKEN`）として利用可能。



### 2. 💾 永続ストレージ (NFS)
Pod が再起動してもデータが消えないように、外部の **NFSサーバー** を利用します。

* **役割:** ユーザーからのアップロードファイル、ログファイル、掲示板のメッセージなどを永続化します。
* **利用手順:**
    1.  `pvc.yaml` で必要な容量をリクエスト。
    2.  `nginx.yaml` の `volumeMounts` で、アプリ内のパス（例: `/usr/share/nginx/html`）にマウント。
    3.  書き込まれたデータは、Pod を削除しても次回起動時に自動で引き継がれます。
